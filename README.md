# 💀 SFhub // UNDERTALE MANIA RPG HUB [KEYLESS]

Welcome to the official repository of SFhub for Roblox Undertale Mania RPG! This is a secure, 100% working raw Lua script base with an integrated minimalist custom GUI. No external internet loaders required, completely safe from crashes and anti-cheat detections.

---

## ⚡ FUNCTIONS:

* **[+] Fly** — Полёт по всей карте для быстрого перемещения.
* **[+] Killaura** — Автоматически наносит урон всем врагам в радиусе.
* **[+] Noclip** — Прохождение сквозь стены и любые текстуры без багов.
* **[+] Player TP** — Моментальный телепорт к выбранному игроку на сервере.

---

## 📜 LOADSTRING / EXECUTION:

Copy this single line of code and paste it into your executor (Delta, Codex, Solara, Xeno):

loadstring(game:HttpGet("https://raw.githubusercontent.com/SFhubTeam/Undertale-Mania-Rpg-script-keyless/refs/heads/main/script.lua"))()
